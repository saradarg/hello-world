# Hello World

A small, pastel-colored Hello World web page.

## Features

- "Hello, World!" centered on the page with a soft shimmering gradient
- Live date and time in the top-right corner
- Light/dark theme toggle (icon-only button) that remembers your choice
- Edit the message with the pencil button — your text is saved in the browser
- Floating pastel background blobs, sparkles, and a confetti burst when you save

## How to run

No install needed. Open `hello-world.html` in any web browser.
